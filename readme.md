# Bank Mockup API

A simple backend mockup of a banking system built with **GraphQL** and **TypeScript**. The project includes basic operations like checking balances, withdrawing, and depositing funds.

## Setup

### Running with Docker

To build and run the project with Docker, use the following command:

```bash
docker-compose up --build
```

Run unit tests
```bash
npm run test
```

## technologies

- GraphQL for API queries and mutations

- TypeScript for type safety

- Docker for containerization

- Jest for unit tests
